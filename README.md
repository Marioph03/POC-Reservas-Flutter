# POC Reservas Barbería — Flutter

Prototipo visual y funcional de una aplicación de gestión para barberías.

## Incluye

- Agenda diaria de reservas y navegación de fechas.
- Indicadores operativos: reservas, ocupación e ingresos previstos.
- Reserva nueva (demostración) y detalle/cierre de una cita.
- Navegación hacia los módulos de Reservas, Clientes, Servicios, Equipo e Informes.
- Diseño responsive para escritorio y móvil, sin dependencias externas.

## Ejecutar

Instala Flutter (SDK >= 3.3), y desde esta carpeta ejecuta:

```powershell
flutter pub get
flutter run
```

La agenda utiliza datos de demostración en memoria, fijados inicialmente al 5 de noviembre de 2026.
